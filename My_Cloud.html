Verified Application Security Index

  • 2FA Email OTP Verification: Dynamic 6-digit verification codes sent via Gmail SMTP for login confirmation.
  • Brute-Force Lockout: Automated 3-attempt restrictions protecting against unauthorized password guessing.
  • CSRF Protection: Cryptographic session tokens validating file uploads and share creations.
  • System Path Shielding: Restricts read/write access to sensitive operating system folders (e.g., C:\Windows).
